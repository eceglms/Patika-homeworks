
# 🪶 TailwindCSS Review Page

Bu proje, **Patika+ Front-End Developer Programı** kapsamındaki **TailwindCSS Review Page** ödevi için hazırlanmıştır.  

---

## 🚀 Kullanılan Teknolojiler
- **HTML5**
- **TailwindCSS (CDN sürümü)**
- Responsive (tüm ekran boyutlarına uyumlu) tasarım

---

## 📄 Sayfa Bölümleri

### 1. Navbar
- Üç adet link sekmesi
- Orta kısımda minimal logo
- Sağda arama çubuğu ve “Log in” butonu

### 2. Hero Alanı
- Büyük başlık, alt açıklama ve iki CTA butonu (“Get Started”, “Learn More”)

### 3. Yorum Kartları (Testimonials)
- 2x2 düzenli grid yapısı
- Her kartta alıntı ikonu, metin ve kullanıcı bilgisi

### 4. İletişim Formu (Contact Us)
- İsim, e-posta, mesaj alanları ve “Send” butonu
- Sayfa sonunda iki kez tekrarlanarak tasarıma uygun hale getirilmiştir

### 5. Footer
- Basit alt menü bağlantıları
- Sosyal medya ikonları

---

## 🧭 Nasıl Kullanılır

1. `tailwind-review-page.html` dosyasını indir.
2. VS Code veya benzeri bir editörde aç.
3. **Go Live (Live Server)** ile çalıştır.
4. Tüm tasarım doğrudan tarayıcıda görüntülenir.

---

## 💡 Geliştirme Notu
Tüm stil sınıfları Tailwind ile inline olarak verilmiştir.  
Ekstra CSS veya JavaScript dosyası kullanılmamıştır.
