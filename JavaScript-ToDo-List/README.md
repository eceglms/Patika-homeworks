# 📝 JavaScript To-Do List

Bu proje, **Kodluyoruz Frontend Web Development Patikası** kapsamındaki **JavaScript Ödev-2 (To-Do List)** çalışmasıdır.  
Kullanıcının günlük yapılacak işlerini listeleyip yönetmesini sağlar.

---

## 🎯 Amaç
- JavaScript ile DOM manipülasyonu yapmayı öğrenmek  
- Listeye yeni öğe ekleme, silme, tamamlandı işaretleme işlemlerini uygulamak  
- Bootstrap Toast bileşeniyle kullanıcıya bildirim göstermek  
- `localStorage` kullanarak verilerin kalıcılığını sağlamak  

---

## ⚙️ Özellikler
- 🟢 **Yeni görev ekleme** (boş ekleme engelli)  
- 🟡 **Görev silme**  
- 🔵 **Tamamlandı işaretleme / geri alma**  
- 🟠 **Toast bildirimi** (Bootstrap 5)  
- ⚪ **Veri kaybını önleme (LocalStorage)**  

---

## 🧱 Kullanılan Teknolojiler
- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Bootstrap 5
