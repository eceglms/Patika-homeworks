# 🪶 TailwindCSS Review Page

Bu proje, **Patika+ Front-End Developer Programı** kapsamındaki **TailwindCSS Review Page** ödevi için hazırlanmıştır.  
Proje, verilen görsel tasarıma **birebir uyacak şekilde** kodlanmıştır.

## 🚀 Kullanılan Teknolojiler
- HTML5  
- TailwindCSS (CDN)  
- Responsive tasarım

## 📄 Sayfa Bölümleri
1. Navbar (sekmeler, logo, arama, Log in)
2. Hero (başlık, açıklama, 2 CTA)
3. Testimonials (2x2 kart düzeni)
4. Contact form (iki tekrar)
5. Footer (linkler + sosyal ikonlar)

## 🧭 Nasıl Kullanılır
1. `index.html` dosyasını tarayıcıda açın (veya VS Code Live Server).
2. Tailwind CDN otomatik yüklenir, ekstra kurulum gerekmez.

## 💡 Not
Tüm stiller Tailwind sınıflarıyla verilmiştir; ekstra CSS/JS kullanılmamıştır.
