# 🍜 Asian Kitchen – Menü Uygulaması

Kore, Japonya ve Çin mutfaklarından örnek yemekleri listeleyen, **kategori filtreleme** (All / Korea / Japan / China) yapan basit bir **HTML + CSS + JavaScript** uygulaması.

> 💻 Demo: `index.html` dosyasını tarayıcıda açmanız yeterli. (VS Code Live Server önerilir.)

---

## ✨ Özellikler

- Dinamik menü listesi (JS ile DOM’a basılır)
- Kategori bazlı filtreleme
- Responsive iki sütunlu yerleşim (Bootstrap grid)
- Google Fonts ile özel tipografi
- Basit, temiz ve düzenli kod yapısı

---

## 🧱 Teknolojiler

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Vanilla JavaScript (ES6+)**
- **Google Fonts (Great Vibes & Zilla Slab)**
